# Contributing

Contributions welcome, especially now - Origin is a few days into beta and the ecosystem is filling in fast.

## Guidelines

- Make sure the resource is actually about Origin, Cursor's git forge, not the Cursor editor/agent or unrelated "origin" content (git remotes, other products named Origin).
- One resource per pull request makes review easier, but small batches are fine.
- Add new entries to the correct category, in the existing style: `- [Title](URL) - One-sentence description.`
- Keep descriptions factual and specific. No marketing language, no unverified claims about traction or stats.
- Dead links, "coming soon" placeholders, and content that's since been retracted or debunked should be removed, not added.
- If a link's status matters (e.g. Alpha API, Origin-native only, no longer maintained), say so in the description.

## Adding a category

Only propose a new top-level category if several links don't fit anywhere existing. Otherwise, existing sections cover most things.

## Pull requests

1. Fork the repo and create a branch.
2. Add your change, following the format above.
3. Open a PR with a short description of what you're adding and why it's relevant.

Maintainers will review for fit, accuracy, and dead links before merging.
